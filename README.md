# WeDate

A personal date-ideas web app: browse a curated library, get a pick for right now, or generate ideas with Gemini.

Live: https://se7enbit.github.io/wedate/

```bash
npm install
npm run dev          # http://localhost:5173/wedate/
npm run typecheck
npm test
npm run build && npm run preview
```

Every push to `main` is typechecked, tested, built and deployed to GitHub Pages.
